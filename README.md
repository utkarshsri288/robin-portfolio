# Robins — React Portfolio Website

Modern, modular, responsive React portfolio application for **Robins**, Consultant with 3+ years of specialized experience in Independent Validation Agency (IVA) projects, government consulting, IT RFPs/EOIs, and data integrity mandates.

Designed following the visual aesthetics, geometric typography, and interaction patterns of **[Rezon Bio](https://portfolio.widehue.co/rezonbio/)**.

---

## ⚡ Quick Start

### 1. Development Server
Run the local Vite dev server with instant hot-reloading:
```bash
cd /Users/apple/Desktop/nikhil/robins
npm run dev
```
Open **http://localhost:3000** in your browser.

### 2. Production Build
Build optimized production assets:
```bash
npm run build
```

### 3. Preview Production Build
```bash
npm run preview
```

## 🛠️ Tech Stack & Architecture
- **Framework**: React 19 (Hooks, Functional Components)
- **Bundler**: Vite 6
- **Icons**: Lucide React
- **Animations**: Framer Motion & CSS3 Transitions
- **Design System**: Rezon Bio Minimalist Geometric Aesthetic (Royal Navy `#1A126E`, Electric Violet `#6554DE`, Amber Accent `#FB9660`)
- **Typography**: Google Fonts `Plus Jakarta Sans` & `Outfit`
